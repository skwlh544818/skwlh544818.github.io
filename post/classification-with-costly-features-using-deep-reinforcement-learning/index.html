处理的问题

本文的应用场景是代价特征分类问题，即算法即需要最小化预期分类的错误，也需要最小化预期产生的成本。需要在二者之间取得一个平衡。

代码

解决的方法

本文提出的一个方法是将强化学习用来顺序选择特征。主要还是 DQN

环境设计

  • 状态：初始状态为 $s_0=(x,y,\empty)$，后续状态为选择第三个参数的特征。
  • 行为：两类行为，一个是特征选择，将特征选入状态中，另一个为分类，即使用现有特征进行分类。
  • 奖励：若进行特征选择的行为，其奖励为 $-\lambda c(f_i)$，若进行分类操作，如果分类正确，则奖励为 0，如果分类错误，则奖励为 -1.
