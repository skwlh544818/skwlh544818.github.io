94. Binary Tree Inorder Traversal

题目

Given the root of a binary tree, return the inorder traversal of its nodes’ values.

例子

Example 1：

Input: root = [1,null,2,3]
Output: [1,3,2]

Example 2:

Input: root = []
Output: []

Example 3:

Input: root = [1]
Output: [1]

限制

  • The number of nodes in the tree is in the range [0, 100].
  • -100 <= Node.val <= 100

Follow up: Recursive solution is trivial, could you do it iteratively?

解法一

这个题目就是要学会二叉树的中序遍历的方法，第一种方法就是使用简单的递归的方法来实现。先递归左子树，然后是中间结点，最后是右子树。

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = []
        def Temp(root):
            if root == None:
                return 
            Temp(root.left)
            res.append(root.val)
            Temp(root.right)
        Temp(root)
        return res

解法二

第二种方法就是使用迭代的方法来完成中序遍历，这个就比较困难了。迭代是使用栈的思想来完成的，用栈来保存结点。算法嵌套了两层循环，内层循环用栈保存左子节点，然后外层循环，则是将栈中结点排除，保存其数值，然后考虑右子节点。


# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = []
        s = []
        p = root
        while p or s:
            while p:
                s.append(p)
                p = p.left
            p = s.pop()
            res.append(p.val)
            p = p.right
        return res

同样是迭代的方法，这是另外一种模仿递归的解法，更加容易看懂。

class Solution:
    def inorderTraversal(self, root: TreeNode) -> List[int]:
        res, stack = [], [(root, False)]
        while stack:
            node, visited = stack.pop()  # the last element
            if node:
                if visited:
                    res.append(node.val)
                else:  # inorder: left -> root -> right
                    stack.append((node.right, False))
                    stack.append((node, True))
                    stack.append((node.left, False))
        return res
