70. Climbing Stairs

问题

You are climbing a staircase. It takes n steps to reach the top.

Each time you can either climb 1 or 2 steps. In how many distinct ways can you climb to the top?

例子

Example 1：

Input: n = 2
Output: 2
Explanation: There are two ways to climb to the top.
1. 1 step + 1 step
2. 2 steps

Example 2:

Input: n = 3
Output: 3
Explanation: There are three ways to climb to the top.
1. 1 step + 1 step + 1 step
2. 1 step + 2 steps
3. 2 steps + 1 step

限制

  • 1 <= n <= 45

解法一

这个题目一个最简单的做法就是递归函数，由于每次只能一层或者两层，所以第n层的走法是由第n-1层的走法和第n-2层的走法之和组成的。这样就形成了一个递归函数，初始为第一层有1种，第二层有2种走法。最后这种方法时间复杂度为$O(nlogn)$，超过了时间界限。

class Solution:
    def climbStairs(self, n: int) -> int:
        if n == 1:
            return 1
        elif n == 2:
            return 2
        else:
            return self.climbStairs(n-1)+self.climbStairs(n-2)

解法二

第二种方法是动态规划的方法，由于我们知道第n层的走法是由第n-1层的走法和第n-2层的走法之和组成，并且我们可以轻易得到第一层有1种，第二层有2种走法。所以我们创建一个列表存储每个楼层的的走法，列表的最后一个元素就是索要求解的答案。这种方法的时间复杂度是$O(n)$，空间复杂度为$O(n)$。

class Solution:
    def climbStairs(self, n: int) -> int:
        if n == 1:return 1
        if n == 2:return 2
        if n>2:
            dp = list(0 for i in range(n+1))
            dp[1]=1
            dp[2]=2
            for i in range(3,n+1):
                dp[i]=dp[i-1]+dp[i-2]
        return dp[n]

由于我们并不需要记录中间的层数有多少中走法，所以我们并不需要设计一个列表来保存，只需要用三个变量来记录前一层的走法和前两层的走法，和当前层的走法。所以空间复杂度降为了$O(1)$。

class Solution:
    def climbStairs(self, n: int) -> int:
        if n == 1:return 1
        if n == 2:return 2
        if n>2:
            pre_1=1
            pre_2=2
            for i in range(3,n+1):
                cur=pre_1+pre_2
                pre_1 = pre_2
                pre_2 = cur
        return cur
