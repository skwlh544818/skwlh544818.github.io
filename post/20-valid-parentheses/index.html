20. Valid Parentheses

问题

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:

  1. Open brackets must be closed by the same type of brackets.
  2. Open brackets must be closed in the correct order.

列子

Example 1：

Input: s = "()"
Output: true

Example 2:

Input: s = "()[]{}"
Output: true

Example 3:

Input: s = "(]"
Output: false

限制

  • 1 <= s.length <= 104
  • s consists of parentheses only '()[]{}'.

解法一

本题的基础解法就是栈的运用，将左括号全部压入栈中，然后遇到右括号就从栈中弹出最新入栈的数据，如果能够配对，则继续。不能配对的话，则输出False。当字符串遍历完成后，如果栈内还有数据，则说明有没有配对完成的单括号，输出False，如果没有数据则输出True。本解法的时间复杂度是$O(n)$，$n$指的是字符串长度。

list的pop函数可以指定pop的位置，默认是最后一位，可以形成栈。如果pop第一位元素，则是队列。

class Solution:
    def isValid(self, s: str) -> bool:
        bullet = []
        for  i in s:
            if i in ['(','[','{']:
                bullet.append(i)
            elif i == ')':
                if len(bullet) != 0 :
                    if bullet.pop() == '(':#default pop the last element
                        continue
                    else:
                        return False
                else:
                    return False
            elif i == ']':
                if len(bullet) != 0 :
                    if bullet.pop() == '[':
                        continue
                    else:
                        return False
                else:
                    return False   
            elif i == '}':
                if len(bullet) != 0 :
                    if bullet.pop() == '{':
                        continue
                    else:
                        return False
                else:
                    return False
        if len(bullet)==0:
            return True
        else:
            return False

解法二

同样是利用栈，但是不像上一个方法那么多的if-else语句，时间和空间利用率也升了一些。使用一个dict将三种括号配对，然后同样是左括号入栈，遇到右括号弹出，不过这次的弹出不再需要单独分别判断。

class Solution:
    def isValid(self, s: str) -> bool:
        d = {'(':')','[':']','{':'}'}
        st = []
        for i in s:
            if i in d:
                st.append(i)
            else:
                if len(st)==0 or d[st.pop()] != i:
                    return False
        return len(st) == 0
