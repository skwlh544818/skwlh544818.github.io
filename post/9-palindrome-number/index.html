9. Palindrome Number

题目

Given an integer x, return true if x is palindrome integer.

An integer is a palindrome when it reads the same backward as forward.

  • For example, 121 is a palindrome while 123 is not.

例子

Example 1：

Input: x = 121
Output: true
Explanation: 121 reads as 121 from left to right and from right to left.

Example 2:

Input: x = -121
Output: false
Explanation: From left to right, it reads -121. From right to left, it becomes 121-. Therefore it is not a palindrome.

Example 3:

Input: x = 10
Output: false
Explanation: Reads 01 from right to left. Therefore it is not a palindrome.

解法一

由题目给的例子可以看出，负数不属于palindrome integer，并且可以很简单看出0是palindrome integer。对于正数，最直接的一种方法就是将每一位数字全部保存到列表中，然后遍历列表。

  1. 将每一位数字保存到列表

  2. 前后索引列表，当后索引小于等于前索引时，遍历结束

  3. 如果前索引所在的值等于后索引的值则继续，否则输出False

  4. 遍历结束，输出True

这个解法的时间复杂度是$O(n+n/2)$，空间复杂度是$O(n)$。这里的n指的是数字的位数

编写代码时应该训练自己的手动调bug的能力，不能依赖于调试器

class Solution:
    def isPalindrome(self, x: int) -> bool:
        if x < 0:
            return False
        elif x == 0:
            return True
        else :
            num_list = []
            temp_x = x
            while temp_x!=0:
                num_list.append(temp_x % 10)
                temp_x = temp_x // 10
            i,j = 0,len(num_list)-1
            while i<j:
                if num_list[i]!=num_list[j]:
                    return False
                else:
                    i+=1
                    j-=1
                    continue
            return True

解法二

第二种方法则不需要创建一个新的列表，只是使用一个数循环累加。这种的时间复杂度是$O(n)$，空间复杂度是$O(1)$。这里的n指的是数字的位数。

  1. 创建x的备份temp_x，sum=0;
  2. 循环判断temp_x是否等于0；
  3. $sum = sum*10+temp_x%10$
  4. $temp_x = temp_x//10$
  5. 循环结束后，如果sum==x，则输出True，否则输出False

从复杂度上看，这个解法优于第一种解法，但是实际结果却不如第一种方法

class Solution:
    def isPalindrome(self, x: int) -> bool:
        if x < 0:
            return False
        elif x == 0:
            return True
        else :
            temp_x = x
            sum = 0
            while temp_x != 0:
                sum = sum*10 + temp_x%10
                temp_x = temp_x // 10 # attention for “//”，not “/”
            if sum == x:
                return True
            else:
                return False

解法三

第三种方法是在第二种方法上修改的，循环运行到中间长度时，sum的结果一定大等于x的结果。如果是palindrome integer，那么sum一定等于x或者sum//10的结果等于x。

  1. 以121为例，循环到中间长度，sum的结果为12，x的结果为1，那么x是等于12//10=1的。

  2. 以1221为例，循环到中间长度，sum和x的结果都为12.

  3. 以1231为例，循环到中间长度，sum的结果是13，x的结果是12，x既不等于sum的结果，也不等于sum//10的结果。

这个方法是有例外的，除0以外的所有以0结尾的数字，都要单独处理，并且他们都不是palindrome integer。

class Solution:
    def isPalindrome(self, x: int) -> bool:
        if x < 0 or (x>0 and x%10==0):#except 0 ,every x ends with 0 is not Palindrome Number.And they will make expression below wronge.  
            return False
        elif x == 0:
            return True
        else :
            sum = 0
            while x > sum:
                sum = sum*10+x%10
                x = x // 10 # attention for “//”，not “/”
            return x==sum or x==sum//10
