35. Search Insert Position

题目

Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be if it were inserted in order.

You must write an algorithm with O(log n) runtime complexity.

例子

Example 1：

Input: nums = [1,3,5,6], target = 5
Output: 2

Example 2:

Input: nums = [1,3,5,6], target = 2
Output: 1

Example 3:

Input: nums = [1,3,5,6], target = 7
Output: 4

限制

  • 1 <= nums.length <= 104
  • -104 <= nums[i] <= 104
  • nums contains distinct values sorted in ascending order.
  • -104 <= target <= 104

解法一

题目要求以$O(logn)$的时间复杂度来完成，也就是说需要使用二分查找法。i和j分别是列表开始的索引和结束元素的索引，然后循环判断i<=j，如果满足，则判断target是否等于列表中间元素，也就是索引为(i+j)//2的元素。等于则直接输出该索引，小于则j=(i+j)//2-1，大于则是i=(i+j)//2+1。最后循环结束，则输出i，说明没有相等的元素，i是应该插入的索引位置。

这种方式有个问题，在有相同的元素的情况下，这个方法没有办法输出相同元素的最小索引位置，只会输出见到的元素。

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        i,j = 0,len(nums)-1
        while i <= j :
            if target == nums[(i+j)//2]:
                return (i+j)//2
            elif target < nums[(i+j)//2]:
                j = (i+j)//2-1
            elif target > nums[(i+j)//2]:
                i = (i+j)//2+1
        return i

解法二

解决上一个方法有相同元素下，无法返回最小索引的位置的问题。i和j分别是列表开始的索引和结束元素的索引的后一位，这样可以确保，如果target时最大数，则会插在结束元素的后一位。while循环改成了判断i<j，这样如果i和j相等就输出。当target小于等于中间元素时，j等于中间索引，否则i等于中间索引+1。

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        i,j = 0,len(nums)
        while i < j :
            if target <= nums[(i+j)//2]:
                j = (i+j)//2
            elif target > nums[(i+j)//2]:
                i = (i+j)//2+1
        return i

解法三

python中有已经封装好的二分查找的库函数，直接调用即可。

class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        import bisect
        return bisect.bisect_left(nums, target)
