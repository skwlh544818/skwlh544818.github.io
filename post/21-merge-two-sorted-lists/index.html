21. Merge Two Sorted Lists

问题

You are given the heads of two sorted linked lists list1 and list2.

Merge the two lists in a one sorted list. The list should be made by splicing together the nodes of the first two lists.

Return the head of the merged linked list.

例子

Example 1：

Input: list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]

Example 2:

Input: list1 = [], list2 = []
Output: []

Example 3:

Input: list1 = [], list2 = [0]
Output: [0]

限制

  • The number of nodes in both lists is in the range [0, 50].
  • -100 <= Node.val <= 100
  • Both list1 and list2 are sorted in non-decreasing order.

解法一

这个解法依旧是一个最基础的解法，创建一个新的ListNode，然后为其创建一个Head，指向这个新的ListNode。如果list1和list2都不为None，则循环遍历两者进行比大小，小的链接上新创建的这个ListNode上。如果有一个list已经为None了，那么指单独遍历那个不为None的list。最后输出Head的下一个结点的下一个结点。时间复杂度为$O(N_1+N_2)$.

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        list3 = ListNode()
        head = ListNode(0,list3)
        while list2 != None and list1!= None:
            if list1.val <= list2.val:
                list3.next = list1
                list1 = list1.next
                list3 = list3.next
            else:
                list3.next = list2
                list2 = list2.next
                list3 = list3.next
        if list2 != None:
            while list2 != None:
                list3.next = list2
                list2 = list2.next
                list3 = list3.next
        if list1 != None:
            while list1 != None:
                list3.next = list1
                list1 = list1.next
                list3 = list3.next
        return head.next.next

解法二

这种方法是一种迭代的方法，如果list1或者list2有一个为空，则输出不为空的那个，如果都为空，则随便输出一个。然后比大小，如果list1小于list2，则list1的下一个结点则作为list1输入到函数中，同理list2.

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        if list1==None or list2==None:
            return list1 if list1 else list2
        if list1.val <list2.val:
            list1.next = self.mergeTwoLists(list1.next,list2)
            return list1
        else:
            list2.next = self.mergeTwoLists(list1,list2.next)
            return list2
