141. Linked List Cycle

问题

Given head, the head of a linked list, determine if the linked list has a cycle in it.

There is a cycle in a linked list if there is some node in the list that can be reached again by continuously following the next pointer. Internally, pos is used to denote the index of the node that tail’s next pointer is connected to. Note that pos is not passed as a parameter.

Return true if there is a cycle in the linked list. Otherwise, return false.

例子

Example 1：

Input: head = [3,2,0,-4], pos = 1
Output: true
Explanation: There is a cycle in the linked list, where the tail connects to the 1st node (0-indexed).

Example 2:

Input: head = [1,2], pos = 0
Output: true
Explanation: There is a cycle in the linked list, where the tail connects to the 0th node.

Example 3:

Input: head = [1], pos = -1
Output: false
Explanation: There is no cycle in the linked list.

限制

  • The number of the nodes in the list is in the range [0, 104].
  • -105 <= Node.val <= 105
  • pos is -1 or a valid index in the linked-list.

Follow up: Can you solve it using O(1) (i.e. constant) memory?

解法一

抛开空间复杂度$O(1)$的限制，可以使用哈希表的方法，如果结点不在哈希表中，则加入，如果有结点已经在哈希表中说明有环，输出True，否则遇到为None的结点则说明没有环，直接输出False。

时间复杂度是$O(n)$，空间复杂度也是$O(n)$

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        s = set()
        while head != None:
            if head not in s:
                s.add(head)
            else:
                return True
            head = head.next
        return False

解法二

本解法使用的方法是Floyd 判圈算法，也叫做龟兔赛跑算法。假想「乌龟」和「兔子」在链表上移动，「兔子」跑得快，「乌龟」跑得慢。当「乌龟」和「兔子」从链表上的同一个节点开始移动时，如果该链表中没有环，那么「兔子」将一直处于「乌龟」的前方；如果该链表中有环，那么「兔子」会先于「乌龟」进入环，并且一直在环内移动。等到「乌龟」进入环时，由于「兔子」的速度快，它一定会在某个时刻与乌龟相遇，即套了「乌龟」若干圈。

根据这个想法，我们可以设计一个快指针，一个慢指针，慢指针每次移动一格，快指针每次移动两格，并且由于判断的循环是两者不相等，所以初始位置快指针需要比慢指针先提前走一格，也就是慢指针的位置是head，快指针的位置是head.next。当慢指针追上快指针，说明链表有环，当快指针为None时，则说明没有环。

时间复杂度是$O(n)$，空间复杂度是$O(1)$。


# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        if not head :
            return False
        slow = head
        fast = head.next
        while fast != slow:
            if not fast or not fast.next :
                return False
            slow = slow.next
            fast = fast.next.next
        return True
