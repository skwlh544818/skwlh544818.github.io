234. Palindrome Linked List

问题

Given the head of a singly linked list, return true if it is a palindrome.

例子

Example 1：

Input: head = [1,2,2,1]
Output: true

Example 2:

Input: head = [1,2]
Output: false

限制

  • The number of nodes in the list is in the range [1, 105].
  • 0 <= Node.val <= 9

Follow up: Could you do it in O(n) time and O(1) space?

解法一

将链表的各个结点的值保存到数组中，然后用双指针来遍历数组来查看是否是回文数组。

时间复杂度为$O(n)$，空间复杂度为$O(n)$

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        s = []
        l = head
        while l!=None:
            s.append(l.val)
            l = l.next
        return s == s[::-1]

解法二

递归的方法，一个指针指向头节点，另一个指针通过递归的形式从后往前循环指向，当两个指针的内容相同时，则前向指针向后走一位，递归指针向前回归一位。当内容不同时，则输出False。

时间复杂度是$O(n)$，空间复杂度是$O(n)$。

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        self.front = head
        def revers(cur = head):
            if cur != None:
                if not revers(cur.next):
                    return False
                if self.front.val != cur.val:
                    return False
                self.front = self.front.next
            return True
        return revers()

解法三

这个解法是先来判断链表的中间节点，可以使用快慢指针的方法，当快指针走到末尾时，慢指针正好在中间位置。也可以获得结点的个数后，循环到中间节点。然后利用反转列表的方式将中间节点后面的链表全部反转，这样就可以比对两边的列表的值了。

时间复杂度是$O(n)$，空间复杂度是$O(1)$

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        slow,fast = head,head
        while fast.next != None and fast.next.next != None:
            slow = slow.next
            fast = fast.next.next
        half = self.revers(slow.next)
        while half!=None:
            if half.val != head.val:
                return False
            half = half.next
            head = head.next
        return True       
    def revers(self,head):
        if head == None:
            return None
        i = head
        j = i.next
        head.next = None
        while j != None:
            temp = i
            i = j
            j = j.next
            i.next = temp
        return i
