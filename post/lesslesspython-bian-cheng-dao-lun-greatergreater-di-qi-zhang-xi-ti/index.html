7.1 处理异常

实现一个满足以下规范的函数。请使用try-except代码块。

def sumDigits(s):
	"""假设s是一个字符串
	返回s中十进制数字之和
	例如，如果s是'a2b3c'，则返回5"""

答案:

def sumDigits(s):
    """假设s是一个字符串
    返回s中十进制数字之和
    例如，如果s是'a2b3c'，则返回5"""
    sum = 0
    try:
        for i in s:
            if i in "0123456789":
                sum += int(i)
        return sum
    except TypeError:
        print(s,"is not string type")

7.2 将异常用作控制流

实现一个满足以下规范的函数。

def findAnEven(L):
    """假设L是一个整数列表
    返回L中的第一个偶数
    如果L中没有偶数，则抛出ValueError异常"""

答案

def findAnEven(L):
    """假设L是一个整数列表
    返回L中的第一个偶数
    如果L中没有偶数，则抛出ValueError异常"""
    flag = True
    for i in L:
        if i%2 == 0:
            return i
    if flag == True:
        raise ValueError("There is no even in",L)
