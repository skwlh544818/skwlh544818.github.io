104. Maximum Depth of Binary Tree

问题

Given the root of a binary tree, return its maximum depth.

A binary tree’s maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

例子

Example 1：

Input: root = [3,9,20,null,null,15,7]
Output: 3

Example 2:

Input: root = [1,null,2]
Output: 2

限制

  • The number of nodes in the tree is in the range [0, 104].
  • -100 <= Node.val <= 100

解法一

这个方法是深度优先遍历的递归方法，递归选择左子树的最大深度，右子树的最大深度，然后选取两边的最大值再加1就是全局的最大深度。

时间复杂度是$O(n)$，n是指结点个数。

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root == None:
            return 0
        else:
            depthl = self.maxDepth(root.left)
            depthr = self.maxDepth(root.right)
            return max(depthl,depthr)+1

解法二

第二种方法是广度优先遍历的迭代方法，将同一深度的结点全部压入队列中，然后一一弹出，并且将下一深度的结点送入队列中，当前一深度结点全部排除，则深度加一。这样全部遍历一遍就可以得到整个的深度。

时间复杂度同样是$O(n)$，$n$指的是结点的个数。

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:return 0
        ans = 0
        temp = []
        temp.append(root)
        while len(temp)!=0:
            s = len(temp)
            while s>0:
                t = temp.pop(0)
                if t.left : temp.append(t.left)
                if t.right: temp.append(t.right)
                s-=1
            ans+=1
        return ans
