136. Single Number

问题

Given a non-empty array of integers nums, every element appears twice except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

例子

Example 1：

Input: nums = [2,2,1]
Output: 1

Example 2:

Input: nums = [4,1,2,1,2]
Output: 4

Example 3:

Input: nums = [1]
Output: 1

限制

  • 1 <= nums.length <= 3 * 104
  • -3 * 104 <= nums[i] <= 3 * 104
  • Each element in the array appears twice except for one element which appears only once.

解法一

如果不考虑题目中说的时间复杂度的限制以及空间复杂度的限制，这个题是很好写的，只需要一个字典即可。字典的key是数组里的数，value是出现的次数，value为1即为要求的数。这种方法是能够通过的，时间复杂度是$O(n)$,空间复杂度也是$O(n)$。

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        d = {}
        for i in nums:
            if i not in d.keys():
                d[i]=1
            else:
                d[i]+=1
        for key,value in d.items():
            if value == 1:
                return key

解法二

这种方法是使用异或的操作，异或是位运算符，相同取0，相反取1，所以对着异或操作有一下性质

  • 任何数和 0 做异或运算，结果仍然是原来的数，即 a⊕0=a。

  • 任何数和其自身做异或运算，结果是 0，即 a⊕a=0。

  • 异或运算满足交换律和结合律，即a⊕b⊕a=b⊕a⊕a=b⊕(a⊕a)=b⊕0=b.

根据第三条规律我们就能知道，有两个相同的数的异或为0，最后全局异或之后得到的结果就是单个数。这样计算就很简单了，时间复杂度是$O(n)$，空间复杂度是$O(1)$，满足题目要求。

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        e = 0
        for i in nums:
            e = e^i
        return e
