101. Symmetric Tree

题目

Given the root of a binary tree, check whether it is a mirror of itself (i.e., symmetric around its center).

例子

Example 1：

Input: root = [1,2,2,3,4,4,3]
Output: true

Example 2:

Input: root = [1,2,2,null,3,null,3]
Output: false

限制

  • The number of nodes in the tree is in the range [1, 1000].
  • -100 <= Node.val <= 100

Follow up: Could you solve it both recursively and iteratively?

解法一

本解法使使用递归的方法，采用每个结点一一比对数值的方法，由于使镜像的判断，所以就是左子树的左节点与右子树的右节点相等即可，当左右结点均为空时是true，其中有一个为空时则是False。

该方法的时间复杂度是$O(n)$，n是指的结点数。

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def ismirror(root1,root2):
            if root1 == None and root2 == None:
                return True
            elif root1 != None and root2 == None:
                return False
            elif root1 == None and root2 != None:
                return False
            else:
                return root1.val == root2.val and ismirror(root1.left,root2.right) and ismirror(root1.right,root2.left)
        return ismirror(root,root)

解法二

将递归修改成迭代的方式就是使用队列，先将两个结点加入进去，然后弹出前两个结点比较数值是否相等，不相等的话直接退出循环，相等的话，则先将第一个结点的左子结点和第二个结点的右子节点加入队列，再将第一个结点的右子节点和第二个的左子节点加入队列，循环至队列为空。

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def ism(u,v):
            tl = []
            tl.append(u)
            tl.append(v)
            while tl:
                tu = tl.pop(0)
                tv = tl.pop(0)
                if tu==None and tv==None:continue
                elif tu== None and tv != None:return False
                elif tu!= None and tv == None:return False
                else:
                    if tu.val != tv.val:return False
                tl.append(tu.left)
                tl.append(tv.right)
                tl.append(tu.right)
                tl.append(tv.left)
            return True
        return ism(root,root)
